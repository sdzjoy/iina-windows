# IINA Windows - 简体中文术语表 (Glossary)

本术语表规范 IINA Windows 版中所有用户可见文本的简体中文翻译。
面向中国大陆普通用户，用词自然、准确、简洁，避免机翻腔。

---

## 通用规则

1. 产品名 **IINA** 不翻译，保持原文。
2. 技术名词如 **mpv**、**Qt**、**OpenGL**、**GPL-3.0** 不翻译。
3. 快捷键标记保持原文（Ctrl、Shift、Alt、Space、Escape 等）。
4. 文件扩展名保持原文（*.mp4、*.srt 等）。
5. 数值和单位之间不加空格（如 `5秒`、`0.25x`），但中英文混排时中文与英文/数字之间加空格（如 `版本 0.1.0`）。
6. 使用中文标点（句号用"。"，逗号用"，"，冒号用"："等）。
7. 省略号使用"…"（半角三点，不用"..."或"……"），与 Windows 系统菜单一致。

## 备注

- 本术语表参考了 IINA macOS 上游 zh-Hans 翻译、VLC 中文版、PotPlayer 中文版的惯用译法。
- "倍速"而非"播放速度"：符合国内视频平台（B站、优酷等）和播放器的习惯用法。
- "截图"而非"截屏"或"屏幕截图"：在播放器语境下，"截图"是对当前视频画面的截取，更准确简洁。
- "历史记录"而非"播放历史"或"记录"：与 Windows 系统和主流浏览器用语一致。
- "深色主题"而非"暗色主题"或"夜间模式"：与 Windows 11 系统设置用语一致。
- 助记符（&）放在中文后面、对应英文字母前面，如"文件(&F)"，符合 Windows 中文软件惯例。
