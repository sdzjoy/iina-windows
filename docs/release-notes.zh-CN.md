# IINA Windows 版 v0.1.0 发布说明

## 概述

IINA Windows 版 v0.1.0 是 IINA 视频播放器在 Windows 平台的首个公开版本。基于 Qt 6 和 libmpv 构建，提供完整的视频播放体验，同时保留了 IINA 的产品设计理念和操作逻辑。

## 新功能

### 播放体验
- 支持主流视频和音频格式的本地文件播放
- 支持 URL 网络流播放（配合 yt-dlp 可播放在线视频）
- 完整的播放控制：播放、暂停、停止、快进快退、逐帧播放
- 倍速控制：支持 0.25x 至 4.0x 倍速调节
- 章节导航：侧边面板和菜单中浏览与跳转章节
- 播放历史：自动记录播放进度，支持续播
- 最近播放：快速访问最近打开的文件
- 截图：支持 PNG、JPG、WebP 格式，可自定义保存目录
- 视频滤镜：亮度、对比度、饱和度、伽马、色相实时调整
- 拖放支持：将视频文件拖入窗口即可播放，拖入字幕文件自动加载

### 字幕体验
- 外部字幕加载：通过对话框或拖放加载外部字幕文件
- 自动匹配：自动扫描同目录下同名的字幕文件并加载
- 字幕轨道切换：支持多字幕轨选择和快捷键切换
- 字幕样式：可调节字体、颜色、描边粗细、位置、延迟和缩放
- 在线搜索：通过 OpenSubtitles API 搜索并下载字幕（需 API 密钥）

### 界面体验
- 深色主题：基于 Material Dark 的现代化深色界面
- 菜单栏：文件、播放、视频、音频、字幕、窗口、帮助
- 右键菜单：在视频区域右键弹出快捷操作菜单
- 侧边面板：播放列表、章节、历史记录三个可切换面板
- OSD 提示：音量、倍速、截图、字幕延迟变化时显示浮层提示
- 设置对话框：通用、视频、音频、字幕四个标签页
- 全屏模式：支持 F 键、双击和按钮切换，鼠标闲置自动隐藏控制栏

### 快捷键
- 33 个可自定义快捷键，覆盖播放、定位、音量、字幕、窗口五大类
- 图形化快捷键配置界面，支持按键录入和恢复默认
- 快捷键配置保存在本地 JSON 文件中

### 简体中文支持
- 完整的简体中文界面翻译
- 基于 Qt 翻译框架（.ts/.qm），支持未来扩展更多语言
- 术语参考 IINA 上游 zh-Hans 翻译和国内主流播放器习惯用法

## 系统要求

- Windows 10 或更高版本
- 支持 OpenGL 3.3 的显卡
- 约 50 MB 磁盘空间

## 已知限制

- 硬件解码默认使用 auto-safe 模式，部分旧显卡可能不支持
- 字幕字体选择目前提供 5 种常用字体，完整字体选择器将在后续版本提供
- 在线字幕搜索需要用户自行获取 OpenSubtitles API 密钥
- 暂不支持文件关联（双击视频文件打开），计划在安装程序中实现
- 暂不支持媒体按键（键盘上的播放/暂停快捷键），计划在下一版本中通过 Windows SMTC 实现
