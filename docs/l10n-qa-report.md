# IINA Windows - 本地化 QA 报告 (L10n QA Report)

## 测试范围

对简体中文翻译进行以下维度的质量检查：
- 字符串长度与截断风险
- DPI 缩放（100% / 125% / 150%）
- CJK 排版与换行
- 标点与空格
- 占位符与格式化符号
- 术语一致性
- 菜单助记符冲突
- 输入法（IME）兼容性

---

## 1. 字符串长度分析

### 方法
对比每个英中翻译对的像素宽度。中文字符约 1.5-2 倍于等宽英文字符宽度，但中文词汇通常比英文短（如 "Settings" 7 字符 → "设置" 2 字符）。

### 结果：通过

| 类别 | 最长英文 | 最长中文 | 宽度变化 | 风险 |
|------|---------|---------|---------|------|
| 菜单项 | "Video &Filters..." (17ch) | "视频滤镜(&I)…" (9ch) | 缩短 | 无 |
| 设置标签 | "Auto-load subtitles from same directory" (40ch) | "自动加载同目录下的字幕" (11ch) | 大幅缩短 | 无 |
| 设置说明 | "Matches subtitle files with..." (57ch) | "匹配与媒体文件同名的字幕文件" (13ch) | 大幅缩短 | 无 |
| OSD | "Subtitle delay: 0.5s" (21ch) | "字幕延迟：0.5s" (10ch) | 缩短 | 无 |
| 按钮 | "Reset All to Defaults" (22ch) | "全部恢复默认" (6ch) | 大幅缩短 | 无 |
| 错误提示 | "Subtitle search requires..." (73ch) | "字幕搜索需要..." (32ch) | 缩短 | 无 |
| 历史时间 | "%1 hours ago" (12ch) | "%1 小时前" (6ch) | 缩短 | 无 |

**结论**：中文翻译普遍比英文原文更短，不存在截断风险。

## 2. DPI 缩放分析

### 100% (96 DPI)
- 菜单项：中文字符宽度约 12-14px，菜单自动适配。无截断风险。
- 设置标签：Layout.preferredWidth: 80/100 用于标签前缀（如"格式："、"字体："），中文 2-3 字符 + 冒号约 48px，80px 宽度充足。
- 侧边面板：280-300px 宽度，面板标题"播放列表"/"章节"/"历史记录"约 72-96px，充足。

### 125% (120 DPI)
- 所有文本等比放大。由于中文比英文短，125% 下的中文比 100% 下的英文还要短或相当。
- 无额外风险。

### 150% (144 DPI)
- 设置标签前缀：80px × 1.5 = 120px 逻辑像素。中文标签"字号："约 48px × 1.5 = 72px。充足。
- 快捷键配置：140px 键位显示区在 150% 下为 210px 逻辑像素。"Ctrl+Shift+O" 约 126px。充足。

**结论**：所有三种缩放级别均无截断风险。

## 3. CJK 排版检查

### 换行
- 所有长文本容器使用 `wrapMode: Text.WordWrap` 或 `Layout.fillWidth: true`。
- 中文不存在英文的"长单词不可断"问题。Qt 会在任意中文字符之间断行。
- 侧边面板列表项标题使用 `elide: Text.ElideRight`，超长文件名会截断并显示"…"。

### 标点
- 验证所有翻译中的标点使用：
  - 冒号：全部使用中文全角冒号"："（格式：、目录：、字号：、延迟：、音量：、倍速：、字幕延迟：）
  - 括号：中文括号"（）"用于"白色（默认）"、"图片文件夹"等
  - 省略号：使用半角"…"（打开文件…、配置快捷键…、浏览…），与 Windows 系统菜单一致
  - 句号：使用中文句号"。"（现代化的 Windows 视频播放器。）

**结论**：通过。标点使用规范一致。
